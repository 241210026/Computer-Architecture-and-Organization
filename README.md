# Computer-Architecture-and-Organization
This repository is for keeping track of my laboratory work in the subject, Computer Architecture and Organisation.
This repository contains a collection of lab exercises and circuit designs developed as part of the Computer Architecture and Organisation course. It serves as a resource for storing Logisim-evolution projects, notes, and example configurations that illustrate key digital logic concepts used in computer systems.

# Overview

Author: Aryan verma (241210026)
Course: Computer Architecture and Organisation
Tools Used: Logisim-evolution (recommended version: v4.0.0), GDB compiler

The repository emphasizes hands-on learning through the design of both combinational and sequential circuits, such as adders, multiplexers, encoders, and related components. Each .circ file represents a complete Logisim-evolution project that can be opened and explored directly within the application.

# Requirements

Logisim-evolution v4.0.0 or newer (https://github.com/logisim-evolution/)
The .circ files contain project-specific settings that allow Logisim to correctly load components and configurations
